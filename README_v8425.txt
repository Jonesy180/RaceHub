OTG! MAIN v8.0.425 — RECOMMENDED CLASS BADGES

Based on v8.0.424 with all SEVEN Custom Upgrade Championships kept intact.
Adds ONE small bright colour-coded FH5 target class badge BEFORE H and E✓
on EVERY official TET2 result-entry car card: Race Off, Relay, Gauntlet,
normal Championship, Swiss, Drag and Long Jump.

D = pink; C = mint; B = blue; A = gold; S1 = orange; S2 = violet; X = red.
The class comes from the ORIGINAL 902-car recommended class catalogue, matched
through each owned car's FH5 catalogue ID. No change to the normal OTG! H button
or the TET2 last-event E✓ indicator. A '?' means the owned car could not be
verified; the app NEVER guesses a class or replaces the H / E✓ flags.

These are RECOMMENDED upgrade targets, NOT the car's current tuned class or
Forza's original PI. No live Forza tuning/PI is read by this app.

No added competitions, rescheduling, reset, or change to the v8.0.424 racing
engine, route assignments, medal rules, Garage, or saved results.
