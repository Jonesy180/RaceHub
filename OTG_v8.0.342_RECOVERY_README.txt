OTG! MAIN v8.0.342 — UPDATE LOOP RECOVERY (NO DATA RESET)

ROOT CAUSE CONFIRMED IN v8.0.341 SERVICE WORKER:
  The app registered v8.0.341, but its navigation redirect still pointed to
  index-v8340.html. Reopening the current page therefore returned users to
  8.0.340, which could offer the update again. This release fixes that mismatch.

CONTENTS: versioned HTML, bootstrap/update bridge, corrected worker and manifests.
No modifications to Garage, Space data, racing engines, honours or app visuals.
The existing v8.0.341 Records Back fix remains in use.

INSTALL:
1) Extract this overlay into C:\RaceHub, replacing only matching files.
   DO NOT DELETE existing files or browser/app/site data.
2) Publish as usual using your 3 git commands:
   git add -A
   git commit -m "OTG MAIN v8.0.342 Update Loop Recovery"
   git push origin main
3) On phone, if installed app remains stuck, open the app WEBSITE in your
   normal mobile browser at its root /index.html URL (NOT /index-v8341.html).
   The older worker only misroutes version-numbered entry pages.
   Accept the new update once if prompted; allow the Safety Backup gate.
4) Return to the installed app and reopen Records.

DO NOT use Clear storage, Clear site data, uninstall, or reset to fix an update
loop: those actions risk locally saved Garage, Spaces and racing results.
